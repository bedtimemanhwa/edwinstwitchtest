# Asset pack: replacing the placeholder art and sounds

All artwork and sounds come from one folder with a `manifest.json`. The game logic never names a file directly, so you can swap in your own Hulk art without touching code.

The placeholder pack is in `public/pack/placeholder/`. It's generated by `npm run assets` (`scripts/gen-placeholder-assets.mjs`).

## Using your own pack

1. Copy `public/pack/placeholder/` to a new folder, for example `assets-custom/`.
2. Replace the files you want, keeping the names, or edit `manifest.json` to point at new names.
3. In `.env`, set `HH_ASSET_PACK=assets-custom`.
4. Restart the server, then refresh the OBS browser source.

## manifest.json

| Key | What | Notes |
|---|---|---|
| `character.idle` / `sleeping` / `flex` | The three character poses | All three are drawn at `character.width` x `character.height`, with the feet at the bottom centre. Transparent PNG, WebP or SVG. The default canvas is 400x520. The engine animates them by moving, scaling and tilting. |
| `props.<id>` | Accessories chat can vote for | `file`, plus `x`, `y` (the centre, as a fraction of the character box) and `w` (width, as a fraction of the character width). `behind: true` draws the prop behind the body, like a cape. The ids must match the dashboard's vote options. |
| `decorations.<id>` | Permanent room unlocks, in unlock order | `gamma-trophy`, `neon-sign`, `punching-bag`, `green-rug`, `arcade-cabinet`, `potted-plant`, `smash-banner`, `giant-fridge`, `lava-lamp`, `championship-belt`. Later unlocks use `fallbackDecoration`. Drawn at 140x140. |
| `room.background` | The room, 1920x1080 | Used in INTRO, BRB and OUTRO, and in LIVE only with `?bg=room`. |
| `room.crate` / `snack` / `rubble` | Gift crate, snack, smash debris | |
| `sounds.<key>` | `wake`, `snack`, `flex`, `smash`, `celebrate`, `unlock` | WAV, MP3 or OGG. Keep them short (under 2 s) and normalised. Volume and mute are in the dashboard. |

A missing file is simply not drawn, so you can replace the art one piece at a time.

**Accessibility:** please avoid rapid flashing in your art. The **Reduced motion** setting (dashboard, or `?reduced=1` on the overlay URL) turns off bobbing, shaking and jumping.
